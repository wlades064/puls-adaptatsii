# Пульс адаптации

«Пульс адаптации» помогает HR заметить трудности сотрудника в первую неделю работы и проследить, как их устранили. В демонстрации используются вымышленные сотрудники и учётные записи.

## Проверить онлайн

1. Откройте [демо](https://wlades64.pythonanywhere.com/) и войдите как `demo-hr`. Демопароль передаётся с заданием.
2. Откройте карточку Дарьи Северовой и её опрос. При истечении срока нажмите «Перевыпустить ссылку». Если ответ уже сохранён, создайте другого вымышленного сотрудника.
3. В отдельной вкладке откройте ссылку. Ответьте «Да» на первые два вопроса и «Нет» на вопрос о помощи. Отметьте «Вопрос касается моего руководителя» и напишите: «Начальник смены поручает закрывать чужие заявки. Третий день доделываю свою работу после смены».
4. Вернитесь на панель HR и откройте новое обращение. Назначьте Полину Лаврову, внесите результат беседы и закройте обращение. История сохранит сигнал, назначение и результат.

## Локальный запуск

Нужен Python 3.12. Из корня распакованного архива выполните в PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
$demoPassword = Read-Host 'Введите пароль для демо (от 12 символов)' -AsSecureString
$env:PULSE_DEMO_PASSWORD = [Net.NetworkCredential]::new('', $demoPassword).Password
$demoPassword.Dispose()
Remove-Variable demoPassword
.\.venv\Scripts\python.exe manage.py seed_demo
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000
```

Откройте http://127.0.0.1:8000/. На macOS и Linux используйте `python3`, `.venv/bin/python` и задайте `PULSE_DEMO_PASSWORD` в окружении перед загрузкой демоданных. База создаётся рядом с `manage.py`.

## Устройство и проверки

Django 5.2 LTS обслуживает HTML-формы и сессии. SQLite хранит сотрудников, опросы, обращения и историю. Один опрос создаёт максимум одно обращение. Отправка формы, создание обращения и смена статуса используют транзакции. Доступ проверяется для каждого обращения. Исполнитель получает поручение от HR, ответы сотрудника доступны HR. Обращение с отметкой о руководителе обрабатывает HR.

```powershell
.\.venv\Scripts\python.exe manage.py test
```

Пройдено 20 автотестов. Они покрывают локальный импорт и повторы задач, а также создание обращения, положительный опрос, явную просьбу связаться, повторы и истёкшие ссылки, CSRF, проверку прав, обязательный результат и откат после ошибки записи. Сквозной сценарий проверен в Chrome с мобильной шириной 390 px, сохранение результата и истории проверено повторным запуском приложения с той же SQLite.

## Ограничения и следующий шаг

В онлайн-демо и при локальном показе используются только вымышленные данные. `runserver` и общие демонстрационные пароли рассчитаны на localhost и вымышленные данные. Приложение использует один опрос на сотрудника. Отправку ссылки выполняет HR. Для реального пилота потребуются отдельные учётные записи, срок хранения ответов и согласование маршрута для обращений о руководителях.


## Локальная проверка импорта из Битрикс24

После миграций запустите из корня проекта:

```powershell
.\.venv\Scripts\python.exe manage.py import_bitrix_hire examples/bitrix-hire.json
```

Затем откройте «Дарья Северова» в кабинете HR. Команда читает локальный JSON с четырьмя полями карточки и тестовым признаком `kind: hire`. Формат файла подготовлен для этой проверки. Он не совпадает с телом события или ответа REST Битрикс24. Повторный запуск сохраняет прежнюю карточку и ссылку. При изменённых данных у того же ID команда сообщает о конфликте.
