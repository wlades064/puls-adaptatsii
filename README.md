# Пульс адаптации

«Пульс адаптации» помогает HR заметить трудности сотрудника в первую неделю работы и проследить, как их устранили. В демонстрации используются вымышленные сотрудники и учётные записи.

## Запуск

Нужен Python 3.12. Из корня распакованного архива выполните в PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
$env:PULSE_DEMO_PASSWORD = Read-Host "Введите пароль для демо (от 12 символов)" -MaskInput
.\.venv\Scripts\python.exe manage.py seed_demo
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000
```

Откройте http://127.0.0.1:8000/. На macOS и Linux используйте `python3`, `.venv/bin/python` и задайте `PULSE_DEMO_PASSWORD` в окружении перед загрузкой демоданных. База создаётся рядом с `manage.py`.

## Сценарий показа

1. Войдите как `demo-hr` с паролем, который задали при запуске. Добавьте вымышленного сотрудника и скопируйте ссылку.
2. Откройте ссылку в приватном окне. Ответьте «Да» на вопросы об обязанностях и поддержке и «Нет» на вопрос об инструментах. Например, у нового кладовщика отсутствует доступ к системе учёта. Отправьте ответы.
3. Обновите панель HR. Откройте обращение «Инструменты и доступы», назначьте Артёма Морозова и укажите, что ему нужно сделать.
4. Выйдите из кабинета HR и войдите как `demo-it` с тем же локальным паролем. Откройте поручение, запишите действие и его результат, затем закройте его.
5. Вернитесь в кабинет HR и откройте закрытое обращение. В истории видны сигнал, назначение и закрытие. Результат сохраняется после перезапуска приложения.

Под `demo-ops` можно проверить, что другому ответственному поручение недоступно. Контрольный положительный опрос сохраняется в карточке сотрудника без обращения. Сотрудник может попросить HR связаться с ним независимо от ответов.

## Устройство и проверки

Django 5.2 LTS обслуживает HTML-формы и сессии. SQLite хранит сотрудников, опросы, обращения и историю. Один опрос создаёт максимум одно обращение. Отправка формы, создание обращения и смена статуса используют транзакции. Доступ проверяется для каждого обращения. Исполнитель получает поручение от HR, ответы сотрудника доступны HR. Обращение с отметкой о руководителе обрабатывает HR.

```powershell
.\.venv\Scripts\python.exe manage.py test
```

Пройдено 8 автотестов. Они покрывают создание обращения, положительный опрос, явную просьбу связаться, повторы и истёкшие ссылки, CSRF, проверку прав, обязательный результат и откат после ошибки записи. Сквозной сценарий проверен в Chrome с мобильной шириной 390 px, сохранение результата и истории проверено повторным запуском приложения с той же SQLite.

## Ограничения и следующий шаг

Это локальный демонстрационный режим. `runserver` и общие демонстрационные пароли рассчитаны на localhost и вымышленные данные. Приложение использует один опрос на сотрудника. Отправку ссылки выполняет HR. Для реального пилота потребуются отдельные учётные записи, срок хранения ответов и согласование маршрута для обращений о руководителях.

Следующий шаг — согласовать признак задачи о приёме в Битрикс24 и проверить права портала. После этого можно связать создание карточки с задачей о приёме и передавать ответственному короткое поручение без исходных ответов.
